# schema.yml knobs (fixed-layout)

Supported knobs:

- node_id.charset, node_id.length, node_id.case, node_id.reserved
- metadata.required_fields, metadata.defaults.type/state, metadata.allowed.type/state
- readme.require_h1, readme.h1_rule, readme.allow_multiple_h1
- time.format/timezone/include_offset (used for timestamps)
- links.syntax/resolve/ignore_code_blocks/count_duplicates (paren_path strict supported)
- index.enabled/mode/auto_repair/stamp
- assets.max_inline_bytes/on_oversize
